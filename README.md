# דשבורד ביקורות גוגל – דרים איילנד

דף אינטרנט מוגן בסיסמה, שמתעדכן כל בוקר ב־10:00 (שעון ישראל) מגיליון הבקרה.

## איך זה עובד

1. כל בוקר GitHub Actions מריץ את `scripts/build.py`.
2. הסקריפט קורא מגיליון הבקרה (קריאה בלבד) את הלשוניות **נתוני דשבורד**, **מדדי גוגל** ו**תחומים**, ומחשב את המדדים.
3. הנתונים מוזרקים לתבנית `template/index.html`.
4. StaticCrypt מצפין את הדף בסיסמה, והוא מתפרסם ב־GitHub Pages.

**המאגר לא מכיל נתונים.** הנתונים נקראים מהגיליון בזמן הבנייה, ונכנסים רק לדף המוצפן.

## סודות (Settings ← Secrets and variables ← Actions)

| שם | תוכן |
|---|---|
| `GOOGLE_SERVICE_ACCOUNT_JSON` | כל התוכן של קובץ המפתח של חשבון השירות |
| `SHEET_ID` | מזהה גיליון הבקרה |
| `DASHBOARD_PASSWORD` | סיסמת הדשבורד (לפחות 14 תווים) |
| `STATICRYPT_SALT` | 32 תווים הקסדצימליים (ניתן בהגדרה) |

## תחזוקה

- **החלפת סיסמה:** לעדכן את `DASHBOARD_PASSWORD`, ואחר כך Actions ← עדכון הדשבורד ← Run workflow.
- **עדכון ידני:** Actions ← עדכון הדשבורד ← Run workflow.
- **אם עדכון נכשל:** GitHub שולח מייל לבעלי המאגר. הדף הקודם נשאר באוויר.
- **פיתוח מקומי:** `python3 dev/make_fixture.py` ואחר כך `DATA_FILE=dev/fixture.json python3 scripts/build.py`. הפלט ב־`dist/index.html`.

## אבטחה

- המאגר ציבורי (תוכנית GitHub Free), ולכן הלוגים גלויים. הסקריפט לא מדפיס נתונים ללוג.
- הדף עצמו נגיש לכל מי שיש לו הקישור, אבל התוכן מוצפן ונפתח רק עם הסיסמה. ההגנה טובה כחוזק הסיסמה.
